# アテナプリント

Windows向けの宛名印刷ソフトです。

Excel形式の「受注業務連絡票」を読み込み、宛名情報を確認・編集したうえで、宛名ラベルや封筒用の印刷データを作成できます。

## ダウンロード

最新版は **[Releases](../../releases)** からダウンロードできます。

Windowsで使用する場合は、Releaseに掲載されている実行ファイル(`atena-print-v1.0.1.exe` のように、版番号つきの名前です)をダウンロードしてください。

※現在の公開版：v1.0.2

## 主な機能

- Excelファイル（`.xlsx` / `.xlsm` / `.xls`）から宛名情報を読み込み
- 複数のExcelファイル・フォルダをまとめて読み込み
- ドラッグ＆ドロップによるファイル・フォルダの追加
- 読み込んだ氏名・住所の一覧表示
- 氏名・住所の編集
- 印刷前のプレビュー
- 宛名ラベルのレイアウト設定
- 封筒用のレイアウト設定
- フォント・文字サイズ・氏名・住所の配置設定
- 用紙設定のプリセット保存
- Word(.docx)またはPDFのファイルを作成して自動的に開く(Officeが入っていないPCでは、PDFを選べます)
- 受注業務連絡票（OZ-151～156）の読み取りに対応

## 使い方

### 1. Excelデータを用意する

「受注業務連絡票」のExcelファイルを用意します。

対応形式：

- `.xlsx`
- `.xlsm`
- `.xls`

### 2. ファイルを読み込む

次のいずれかの方法でExcelファイルを読み込みます。

#### 規定フォルダを使用する場合

「規定フォルダ作成」を押すと、アプリと同じ場所に

`入力受注業務連絡票`

フォルダが作成されます。

そのフォルダにExcelファイルを入れ、「既定フォルダを再読込」を押します。

#### ファイル・フォルダを直接追加する場合

右側のドラッグ＆ドロップ欄にExcelファイルまたはフォルダをドラッグ＆ドロップできます。

また、「ファイルを追加...」「フォルダを追加...」から指定することもできます。

### 3. データを確認・編集する

読み込まれた宛名データを一覧で確認します。

必要に応じて、一覧内の「氏名」「住所」をダブルクリックして編集できます。

### 4. 用紙を設定する

「用紙設定...」から、以下の設定を変更できます。

- 出力様式(Word / PDF)
- フォント
- 文字サイズ
- 氏名・住所の配置
- 宛名シールの設定
- 封筒の設定
- 印刷枠の設定

設定はプリセットとして保存できます。ただし、「出力様式」はこのPC共通の設定で、プリセットには含まれません。

設定・プリセットは、このPCのユーザー領域(`%APPDATA%\宛名印刷\`、通常は `C:\Users\<ユーザー名>\AppData\Roaming\宛名印刷\`)の `atena_seal_settings.json` に保存されます。アプリ本体を同じPC内で別の場所へ移動しても、設定はそのまま使われます。

- v1.0.1以前の設定ファイル(アプリと同じフォルダにあったもの)は、v1.0.2の初回起動時に自動でコピーして引き継ぎます(元のファイルは残ります)。
- 別のPCへ設定を移すときは、上記フォルダの `atena_seal_settings.json` をコピーしてください。
- 「入力受注業務連絡票」フォルダは、従来どおりアプリと同じ場所を基準にします。アプリを移動するときは、一緒に移動してください。

### 5. 宛名印刷

出力ファイルの保存先を設定し、「宛名印刷」ボタンを押します。

「用紙設定...」の「レイアウト種別」の右隣にある「出力様式」で選んだ形式(Word または PDF)のファイルが作成され、自動的に開きます。

- **Word(.docx)**: 従来の出力です。.docx を開けるアプリ(WordやLibreOfficeなど)が必要です。
- **PDF(.pdf)**: Word等のOfficeが入っていないPCでも、PDFビューア(Edge・Adobe Readerなど)があれば開いて印刷できます。PDFを印刷するときは、必ず「拡大/縮小なし(実際のサイズ)」で印刷してください。初めて使うときは、普通紙に試し刷りして位置を確認してください。

## 対応する受注業務連絡票

受注業務連絡票（OZ-151～156）の読み取りに対応しています。

1つのExcelファイルに複数の記入済みシートがある場合、シートごとに別の宛名データとして扱います。

宛名の判定では、受注業務連絡票の「送付先」の選択内容を使用します。

入力内容に不整合がある場合は、一覧の「状態」にエラーが表示されます。

## ビルド

このプロジェクトではGitHub Actionsを使用してWindows向けEXEを自動ビルドします。

GitHub ActionsでPyInstallerを実行し、

`宛名印刷.exe`

を生成します。

`v1.0.1` のようなタグを push すると、ビルドしたEXEが `atena-print-v1.0.1.exe` のようにタグ名つきの名前でReleasesに自動で添付されます。
